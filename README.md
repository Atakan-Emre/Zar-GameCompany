## 🏢 Şirket Tanıtımı

**Zar Game Company**, artırılmış gerçeklik (AR) teknolojilerini kullanarak çocuklar ve gençler için eğitici mobil uygulamalar geliştiren yaratıcı bir teknoloji şirketidir. Misyonumuz, AR teknolojisini kullanarak öğrenmeyi eğlenceli, interaktif ve etkili hale getirmektir.

### 🎯 Vizyon & Misyon
- **Vizyon:** AR teknolojileriyle eğitimin geleceğini şekillendiren, dünya çapında tanınan eğitim teknolojisi lideri olmak
- **Misyon:** Çocukların merak duygusunu harekete geçiren, yaratıcılıklarını destekleyen ve öğrenme süreçlerini eğlenceli hale getiren AR tabanlı eğitici uygulamalar geliştirmek

### 💡 Şirket Değerleri
- **İnovasyon:** En son teknolojilerle yaratıcı çözümler
- **Eğitim Odaklı:** Çocuk gelişimi ve öğrenme merkezli tasarım  
- **İş Birliği:** Eğitimciler ve ailelerle ortak çalışma

### 🗺️ Macera Haritası: Dünya Kültürleri AR Uygulaması

**Macera Haritası**, çocukların uçuş esnasında farklı ülkeleri, kültürleri ve dilleri eğlenceli ve interaktif bir şekilde keşfetmelerini sağlayan artırılmış gerçeklik tabanlı mobil uygulamadır.

#### ⭐ Öne Çıkan Özellikler

**📍 AR Deneyimleri:**
- **3D İnteraktif Dünya Haritası:** Fiziksel yüzeylerde görüntülenebilen, dokunmatik dünya haritası
- **Kültürel Yapı Modelleri:** Eyfel Kulesi, Pisa Kulesi, Özgürlük Heykeli gibi ünlü yapıların 3D AR modelleri
- **Gerçek Zamanlı Etkileşim:** Fiziksel nesneleri tanıma ve dijital içerikle etkileşim

**🎮 Eğitici İçerikler:**
- **Dil Öğrenimi:** Her ülkeye özgü kelime ve temel cümle öğrenimi
- **Kültür Aktiviteleri:** Yemek pişirme, geleneksel dans, müzik aletleri tanıma
- **Coğrafi Bilgiler:** Harita eşleştirme, bayrak tanıma, başkent bulma oyunları

**🏆 Motivasyon Sistemi:**
- **Kaşif Pasaportu:** Ziyaret edilen ülkelerin damga koleksiyonu
- **Rozet Sistemi:** Farklı başarılar için kazanılan özel rozetler
- **Avatar Kişiselleştirme:** Kullanıcıya özel kaşif karakteri oluşturma

**👨‍👩‍👧‍👦 Güvenlik & Ebeveyn Kontrolü:**
- **Oturum Süresi Yönetimi:** Yaş grubuna uygun kullanım süreleri
- **Göz Sağlığı Koruması:** Düzenli mola hatırlatıcıları
- **İçerik Filtreleme:** Ebeveyn onaylı eğitici içerikler

#### 🛠️ Teknik Altyapı
- **Framework:** React Native (Expo)
- **Programlama Dili:** TypeScript
- **AR Teknolojisi:** ViroReact, ARCore/ARKit
- **3D Kütüphaneler:** Three.js, Expo Three
- **UI Framework:** React Native Reanimated

- **İnteraktif Hesap Makinesi:** Havada yazılan sayıları tanıyan AR hesap sistemi
- **Matematik Grafikleri:** 3D fonksiyon grafikleri ve analiz araçları

**🎯 Öğrenme Modülleri:**
- **Temel Geometri:** Şekil tanıma, alan ve hacim hesaplamaları
- **Sayı Öğrenimi:** Temel aritmetik işlemler ve sayı kavramları
- **Problem Çözme:** Adım adım çözüm yöntemleri ve mantık geliştirme

**🏅 İlerleme Sistemi:**
- **Seviyeli Öğrenme:** Yaş grubuna uygun zorluktaki aktiviteler
- **Başarım Rozetleri:** Matematik becerilerine göre kazanılan özel rozetler
- **İlerleme Analizi:** Detaylı performans raporları ve öğrenme önerileri

**🎨 Etkileşimli Oyunlar:**
- **Matematik Bulmacaları:** Zeka geliştirici matematik oyunları
- **Hız Testleri:** Hesaplama hızını artıran mini oyunlar
- **Rekabet Modu:** Arkadaşlarla matematik yarışmaları

- **Framework:** Flutter 3.0+
- **Programlama Dili:** Dart
- **AR Teknolojisi:** ARCore (Android), ARKit (iOS)
- **3D Modelleme:** Blender entegrasyonu
- **AI Teknolojisi:** Makine öğrenmesi ile kişiselleştirilmiş öğrenme

## 🛠️ Geliştirme ve Kurulum

### Macera Haritası için Kurulum

```bash
# 1. Gerekli ortamı hazırlayın
npm install -g expo-cli

# 2. Proje klasörüne gidin
cd project/MaceraHaritasi

# 3. Bağımlılıkları yükleyin
npm install
# veya
yarn install

# 4. Geliştirme sunucusunu başlatın
npm run dev
# veya
yarn dev
```

### MathAR için Kurulum

```bash
# 1. Flutter SDK'yı yükleyin
# https://flutter.dev/docs/get-started/install

# 2. Proje klasörüne gidin
cd project/MathAR

# 3. Bağımlılıkları yükleyin
flutter pub get

# 4. Cihaz bağlantısını kontrol edin
flutter devices

# 5. Uygulamayı çalıştırın
flutter run
```

### Web Sitesi için Geliştirme

```bash
# Yerel geliştirme sunucusu başlatma
python -m http.server 8000

# Tarayıcıda açın: http://localhost:8000
```
